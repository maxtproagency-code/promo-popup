# Promo Popup — заміна Claspo

Легкий попап без залежностей і без адмінки: тексти й умови показу правляться в коді.
Ядро лежить на maxt.pro, а на клієнтські сайти підключається через GTM.

**Статус:** v1.1.0 — два режими, два клієнти (Kika, Harvest), українська.

| Режим | Що робить | Клієнт |
|---|---|---|
| `promo` | Текст + промокод, який копіюється | Kika |
| `email` | Текст + поле email, відправка на Apps Script | Harvest (кошик) |

## Структура

```
popup/
├── src/promo-popup.js          ← ядро (заливається на maxt.pro)
├── clients/
│   ├── kika/                   ← промокод
│   │   ├── gtm-tag.html
│   │   └── preview.html
│   └── harvest/                ← email + кошик
│       ├── gtm-tag.html
│       └── preview.html
└── README.md
```

## Деплой ядра на maxt.pro

1. Залити `src/promo-popup.js` на сервер (FTP / файловий менеджер хостингу) за шляхом
   `/promo-popup/v1/promo-popup.js` у корені сайту (поруч із `wp-content`).
2. Перевірити, що файл відкривається напряму: https://maxt.pro/promo-popup/v1/promo-popup.js
   і що віддається з типом `application/javascript` (DevTools → Network).
3. Якщо стоїть кеш-плагін / Cloudflare — статичні .js зазвичай не чіпаються, але після оновлення
   ядра завжди піднімати `?v=` у GTM-тегу.

> Шлях `/v1/` — мажорна версія. v1.1 сумісна з v1.0: конфіги без `mode` працюють як раніше.
> Ламаючі зміни → нова папка `/v2/`.

## Підключення на сайті клієнта (GTM)

1. GTM → Теги → Новий → **Спеціальний HTML** → вставити вміст `clients/<клієнт>/gtm-tag.html`.
2. Тригер: **All Pages** (Page View) або DOM Ready. Для режиму `email` додатково — події кошика.
3. Preview → відкрити сайт з `?promo_debug=1` → перевірити → Опублікувати.
4. **Вимкнути Claspo** (поставити його тег на паузу).

## Конфіг

### Спільне

| Поле | Що робить | За замовчуванням |
|---|---|---|
| `id` | Ключ історії показів. **Новий id = попап знову побачать усі** | `promo` |
| `mode` | `promo` або `email` | `promo` |
| `title`, `text` | Заголовок і текст. Дозволено `<br>`, `<b>`, `<i>`, `<a href="…">` | |
| `start`, `end` | Дати `YYYY-MM-DD`, включно. Поза ними попап не показується | `null` |
| `delaySec` | Показ через N секунд | `10` |
| `scrollPercent` | Або після прокрутки N% | `0` |
| `exitIntent` | Або коли курсор іде за верхню межу (лише десктоп) | `false` |
| `inactivitySec` | Або після N секунд без дій | `0` |
| `hideDaysAfterClose` | Пауза після закриття, днів | `3` |
| `excludeUrls` | Підрядки URL, де не показувати | `[]` |
| `dataLayer`, `eventPrefix` | Пуші подій у dataLayer | `true`, `promo_popup` |
| `disabled` | Аварійне вимкнення | `false` |
| `theme.*` | Шрифт, кольори, кегль заголовка, радіус, ширина | |

Спрацьовує той тригер, що настав раніше. Тригери показу незалежні: можна ввімкнути всі чотири.

### Режим `promo`

| Поле | Що робить |
|---|---|
| `code` | Промокод |
| `copiedText` | Текст після копіювання (2 с) |
| `hideDaysAfterCopy` | Пауза після копіювання коду, днів |

### Режим `email`

| Поле | Що робить |
|---|---|
| `form.button`, `form.placeholder`, `form.label` | Підписи форми |
| `form.consentMode` | `checkbox` (обовʼязкова згода), `notice` (лише текст), `none` |
| `form.consentText` | Текст згоди, можна з посиланням `<a href="…">` |
| `form.successTitle`, `form.successText`, `form.successCloseSec` | Екран після відправки |
| `submit.endpoint` | URL, куди йде POST (веб-додаток Apps Script) |
| `submit.token` | Спільний рядок, який перевіряє сервер |
| `submit.minSeconds` | Сабміт швидше — вважаємо ботом, нічого не відправляємо |
| `submit.retry` | Невдалі сабміти складаються в чергу й повторюються на наступній сторінці |
| `cart.storageKey` | Ключ `localStorage`, де лежить кошик: `{items:[{id,name,price,qty}], ts}` |
| `cart.required` | Без товарів попап не показується |
| `cart.watchMinutes` | …але стільки хвилин чекаємо, поки товар додадуть |
| `hideDaysAfterSubmit` | Пауза після успішної підписки, днів |

**Що йде на сервер:** `{token, type, popup, email, cid, items:[{id,qty}], page, consent, ms, ts}`.
`cid` — client_id GA4 з cookie `_ga`; якщо cookie немає, поле порожнє.

**Захист:** приховане поле-приманка, мінімальний час до сабміту, валідація email.
Токен у коді попапа видно всім, тому решта перевірок — на боці Apps Script
(валідація, дедуплікація, добовий ліміт, журнал `subscribe_log`).

## Налагодження

- `?promo_debug=1` — показати одразу, ігнорує дати / частоту / виключення / кошик, пише лог у консоль `[PromoPopup]`.
- `?promo_reset=1` — очистити історію показів і чергу відправки.
- У консолі: `PromoPopup.show()`, `PromoPopup.cart()`, `PromoPopup.version`.
- Історія: DevTools → Application → Local Storage → `promo_popup_<id>`, черга — `promo_popup_queue`.
- `clients/harvest/preview.html` має кнопки «наповнити кошик» і «перемкнути помилку відправки»;
  справжній запит не йде, payload видно в лозі сторінки.

## Що вміє ядро

- Shadow DOM: стилі сайту не ламають попап і навпаки.
- Копіювання: Clipboard API → фолбек `execCommand` (старий Safari, вебвʼю Instagram/Facebook) → якщо все заблоковано, код виділяється для ручного копіювання.
- Відправка: `fetch` із `text/plain` (без preflight) → фолбек `sendBeacon` → черга в `localStorage`.
- Закриття: хрестик, клік по фону, Esc. Фокус повертається туди, де був.
- Доступність: `role="dialog"`, `aria-modal`, фокус-трап, `aria-live` для помилок і успіху, `prefers-reduced-motion`.
- Захист від подвійного запуску тегу GTM.
